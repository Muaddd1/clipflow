# ClipFlow — The Operating System for Your Content Business

> A premium SaaS command center for video creators. Manage ideas, scripts, sponsors, and analytics in one beautiful workspace.

**Live Demo:** https://clipflow-demo.vercel.app

## Features

- **Command Center Dashboard** — Stats, pipeline view, and quick actions at a glance
- **Content Library** — Track all your videos across YouTube, TikTok, Instagram, X, and LinkedIn
- **Idea Vault** — Capture and develop content ideas with viral scoring and trend tracking
- **Script Studio** — Write and version-control your video scripts
- **Content Calendar** — Schedule content across all platforms
- **Sponsor CRM** — Manage brand deals, payments, and deadlines
- **Analytics** — Track views, engagement, followers, and revenue
- **Repurpose Workspace** — Turn one piece of content into many formats
- **Media Library** — Store and organize your assets
- **Settings** — Full customization of platforms, categories, and notifications

## Tech Stack

- **Next.js 16** with App Router and Turbopack
- **Tailwind CSS v4** with `@theme inline` syntax
- **Radix UI** for accessible primitives
- **Lucide React** icons
- **Sonner** for toast notifications
- **localStorage** for data persistence

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy to Vercel

```bash
npm i -g vercel
vercel deploy
```
